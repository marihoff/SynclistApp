SyncList PWA - Seu Organizador Pessoal Offline
O SyncList é um aplicativo web progressivo (PWA) multifuncional projetado para ajudar a organizar diversas áreas da sua vida. Desde tarefas diárias e listas de compras até planejamentos de viagem e anotações rápidas, tudo é salvo diretamente no seu navegador, garantindo que seus dados estejam sempre disponíveis, mesmo sem conexão com a internet.

Este projeto foi desenvolvido como um exemplo prático de um aplicativo React moderno, focado em uma experiência de usuário limpa, responsiva e totalmente funcional no front-end, sem a necessidade de um backend.

✨ Funcionalidades Principais
Múltiplos Módulos: Gerencie diferentes aspectos da sua rotina em um só lugar:

Tarefas: Crie listas de afazeres com data e hora.

Compras: Organize suas compras por categoria.

Atividades: Acompanhe hábitos e metas diárias.

Notas: Faça anotações rápidas com um sistema de post-its virtuais.

Viagem e Cuidados: Use checklists prontas para não esquecer de nada antes de viajar ou para cuidar da casa e do carro.

100% Offline: Graças à arquitetura PWA e ao uso do localStorage, o aplicativo funciona perfeitamente sem internet.

Privacidade por Usuário: Os dados são isolados por e-mail. Cada login acessa um espaço de armazenamento separado, garantindo a privacidade das suas listas.

Interface Moderna: Construído com Tailwind CSS para um design limpo, responsivo e com suporte a tema claro e escuro.

Instalável: Como um PWA, o SyncList pode ser "instalado" na tela inicial do seu celular ou na área de trabalho do seu computador para um acesso rápido.

🛠️ Tecnologias Utilizadas
React: Biblioteca principal para a construção da interface de usuário.

Tailwind CSS: Framework de estilização para um desenvolvimento rápido e consistente.

Hooks do React: useState, useEffect e hooks customizados para gerenciamento de estado e persistência de dados.

Browser localStorage: Utilizado como "banco de dados" local para salvar todas as informações do usuário.

🚀 Como Executar o Projeto
Para rodar este projeto localmente, siga os passos abaixo:

Clone o repositório:

git clone [https://github.com/SEU-USUARIO/NOME-DO-REPOSITORIO.git](https://github.com/SEU-USUARIO/NOME-DO-REPOSITORIO.git)

Navegue até a pasta do projeto:

cd NOME-DO-REPOSITORIO

Instale as dependências:

npm install

Inicie o servidor de desenvolvimento:

npm start

Abra seu navegador e acesse http://localhost:3000.
