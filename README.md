# SyncList (Vite + React + Tailwind)

Projeto já **pronto para rodar** com o seu componente `SimplePwaMultiListApp`.
Inclui Vite, React 18 e Tailwind configurados (dark mode por classe).

## Como rodar

```bash
# 1) instalar deps
npm install

# 2) ambiente de desenvolvimento
npm run dev
# abra a URL indicada (ex.: http://localhost:5173)

# 3) build de produção
npm run build

# 4) pré-visualização local do build
npm run preview
```
