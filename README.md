# 📋 SyncList PWA – Seu Organizador Pessoal Offline

O **SyncList** é um aplicativo web progressivo (**PWA**) multifuncional, projetado para ajudar a organizar diversas áreas da sua vida.  
Desde tarefas diárias e listas de compras até planejamentos de viagem e anotações rápidas, tudo é salvo diretamente no navegador, garantindo que seus dados estejam sempre disponíveis — **mesmo sem conexão com a internet**.

Este projeto foi desenvolvido como um exemplo prático de um **aplicativo React moderno**, focado em uma experiência de usuário limpa, responsiva e totalmente funcional no front-end, **sem a necessidade de backend**.

---

## ✨ Funcionalidades Principais

### 🧩 Múltiplos Módulos
Gerencie diferentes aspectos da sua rotina em um só lugar:

- ✅ **Tarefas**: Crie listas de afazeres com data e hora  
- 🛒 **Compras**: Organize suas compras por categoria  
- 🔄 **Atividades**: Acompanhe hábitos e metas diárias  
- 📝 **Notas**: Faça anotações rápidas com post-its virtuais  
- ✈️ **Viagem e Cuidados**: Checklists prontas para viagens, casa e carro  

---

### 🌐 100% Offline
- Funciona perfeitamente sem internet  
- Utiliza **localStorage** para persistência dos dados  

### 🔐 Privacidade por Usuário
- Os dados são isolados por **e-mail**
- Cada login acessa um espaço de armazenamento separado  

### 🎨 Interface Moderna
- Desenvolvido com **Tailwind CSS**
- Design limpo, responsivo
- Suporte a **tema claro e escuro**

### 📲 Instalável
- Pode ser instalado como app no celular ou desktop
- Acesso rápido direto da tela inicial

---

## 🛠️ Tecnologias Utilizadas

- **React** – Biblioteca principal para construção da interface  
- **Tailwind CSS** – Estilização moderna e responsiva  
- **React Hooks** – `useState`, `useEffect` e hooks customizados  
- **Browser localStorage** – Armazenamento local dos dados

git clone

Navegue até a pasta do projeto:

Instale as dependências:

npm install

Inicie o servidor de desenvolvimento:

npm start

Abra seu navegador e acesse http://localhost:3000.
